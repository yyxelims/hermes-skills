# URL 验证与站点发现模式

## 何时使用百度 AI 搜索验证 URL

当 urllib 或 Browser 访问某个站点超时时，不要盲目重试。按以下顺序：

1. **先用百度搜索验证**：`python3 /Users/you/quant-lab/baidu_search.py "机构名+官网+栏目名"`
2. **检查搜索结果**：
   - 如果有该站点的近期文章（日期 < 7 天）→ URL 正确，是网络问题 → 标注"不可达"
   - 如果搜索结果指向不同域名 → URL 可能已变更 → 用搜索到的正确 URL 重试
   - 如果搜索不到该站点 → URL 可能错误 → 询问用户或搜索其他关键词
3. **如果搜索到领导信息/文章摘要**：直接从搜索结果正文中提取可用数据，标注数据来源为"百度搜索"

## 实战案例

### 案例1：北京市市场监督管理局
- 初试 `scjgj.beijing.gov.cn`（HTTPS）→ 超时
- 百度搜索确认：URL 正确，2026-08-05 仍有文章更新
- 百度搜索直接返回领导信息摘要：局长高念东、副局长唐云华/邓慧敏/李明
- 发现领导栏目路径：`scjgj.beijing.gov.cn/jgzq/ldjs/`
- 结论：URL 正确，网络不可达，领导数据从百度获取

### 案例2：北京市政务服务和数据管理局
- 域名 `zwfwj.beijing.gov.cn` 与用户文档中提到的名称一致
- 百度确认域名存在，但浏览器超时
- 结论：网络不可达

### 案例3：网联清算域名
- 文档中写 `nhunionpay.com` → DNS 失败
- 百度搜索确认正确域名为 `nucc.com`
- 新闻中心 URL：`nucc.com/newsCenter`

### 案例4：银联域名
- `unionpay.com.cn` → SSL 证书 CN 不匹配
- 百度搜索后尝试 `unionpay.com` → 可用
- 新闻列表 URL：`unionpay.com/upowhtml/cn/templates/newsList-01017/...`

## 搜索关键词模板

| 目的 | 关键词 |
|------|--------|
| 找官网 | `{机构名} 官网 网址` |
| 找领导页 | `{机构名} 领导信息 领导班子 {域名片段}` |
| 找通知公告 | `{机构名} 通知公告` |
| 找政策文件 | `{机构名} 政策法规` |
| 确认网站活跃 | `{域名} 最新 2026` |
