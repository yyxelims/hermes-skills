# 领导简历清理 + 数据交付规范

## 简历清理函数

PBC 官网领导的 `bio_raw` 字段包含噪音（文章列表、活动列表、"更多>>"标记等），写入 Excel 前必须清理：

```python
def clean_bio(raw):
    """Extract only the resume portion, removing article lists"""
    if not raw: return ''
    idx = raw.find('更多>>')
    if idx > 0:
        raw = raw[:idx].strip()
    return raw
```

清理前示例（600字）：
"潘功胜，男，汉族，1963年7月生，研究生学历、经济学博士学位，中共党员，现任中国人民银行党委书记、行长。 更多>> 中国人民银行行长潘功胜在香港货币与固定收... 2026-07-07 中国金融结构的变迁..."

清理后（53字）：
"潘功胜，男，汉族，1963年7月生，研究生学历、经济学博士学位，中共党员，现任中国人民银行党委书记、行长。"

## Excel 写入前文本清理

```python
import re
def clean(s):
    if not s: return ''
    return re.sub(r'[\x00-\x08\x0b\x0c\x0e-\x1f\x7f-\x9f]', '', str(s))
```

这些控制字符在网页源码中常见但 Excel 不接受。

## 交付规范

1. **先内容，后 URL**：Excel 单元格第一优先级是正文/简历/名单内容，URL 放单独列
2. **诚实标注数据来源**：如果内容是结构化摘要而非原文，在 Sheet 标题或首行标注（如 "⚠️ 结构化摘要，原文需 Browser 访问"）
3. **不要用摘要冒充原文**：用户会打开 Excel 逐行检查。被发现用摘要替代原文会要求重做。
4. **任免内容虽短也应写入**：北京人事任免每条只有一句话（"XX当选XX区区长"），但这一句话就是原文全文，必须写入。

## README.md 格式（关键）

用户定稿格式：每步按"输入→操作→输出→实际遇到的坑"四个子部分。

```
## 第X步：xxx

### 输入
### 操作
### 输出
### 实际遇到的坑
```

参考模板：`full-workflow(1).md`、`CARD_WORLD_SKILLS_FLOW(1).md`。

**严禁**写成章节式文章。用户会说"步骤呢？以后不要再让我提醒你了"。

## Excel 最终检查清单

每次生成 Excel 后必查：
- [ ] 日期格式全部 YYYY-MM-DD（无 `/` 或 `.` 分隔）
- [ ] 日期降序排列（有日期的在前，无日期的沉底）
- [ ] 摘要无空值（最差也要 `【来源】标题`）
- [ ] 无导航页噪音（政府信息公开指南等）
- [ ] 站点名无 "?" 或 policy_tracker 原始内部名
- [ ] 控制字符已清理（`[\x00-\x08\x0b\x0c\x0e-\x1f\x7f-\x9f]`）
- [ ] 文件在项目根目录，不在子目录
