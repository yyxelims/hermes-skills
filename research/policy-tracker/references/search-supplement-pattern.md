# 搜索补全模式 — 抓常规爬虫遗漏的重大事件

## 原理

常规爬虫从固定数据源（pbc.gov.cn/nfra.gov.cn等）定时抓取。但有些重大事件不会出现在这些固定源上：
- 领导变动（部级走国务院任免/新华社发布，不在官网）
- 大额处罚（可能先被媒体爆出）
- 新规征求意见（发布渠道不固定）

搜索补全用百度 AI Search API 定向搜索特定关键词，弥补常规爬虫的盲区。

## 搜索主题（优先级排序）

1. **信用卡处罚** — "信用卡 中心 被罚 2026年 监管 处罚"
2. **消费金融政策** — "消费金融 2026年 监管 政策 贷款 利率 新规"
3. **支付机构处罚** — "支付机构 罚单 2026年 央行 处罚"
4. **领导变动** — "中国人民银行 金融监管总局 党委委员 任免 局长 2026年"

## 来源过滤

搜索结果中必须过滤：
- `baijiahao.baidu.com` — 自媒体，不可靠
- `mp.weixin.qq.com` — 微信文章，正文不可抓
- `sohu.com` — 转载，质量低

优先保留：
- 官方源（.gov.cn, pbc.gov.cn, nfra.gov.cn）
- 专业财经媒体（10jqka.com.cn, 163.com, cctv.com）
- 多源交叉验证的文章

## 验证流程

每条搜索结果必须：
1. 打开原文 URL，检查正文是否确实含关键声明
2. 同一事件找至少 2 个不同来源交叉确认
3. 标注验证状态（✅已确认 / ⚠️单源待确认）

## 示例（已验证真实）

|------|------|------|:--:|

## 脚本

`search_supplement.py` — 运行一次消耗 ~4 次百度搜索额度（含 4 个主题）。
输出 `baidu_supplement_YYYYMMDD_HHMMSS.json`，被 `build_final.py` 自动合并。

## 频率

建议每日运行一次。搜索结果 12-24 小时内不会有大变化（百度索引更新周期）。
