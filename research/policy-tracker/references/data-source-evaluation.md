# 数据源评估 — 已验证可用的垂直金融数据源（2026-08-10）

## ✅ 推荐使用（已验证正文率+内容质量）

### 移动支付网 (mpaypass.com.cn)
- **URL**: `/policy.html` (列表) → `/news/YYYYMM/HHMMSS.html` (详情)
- **方法**: Browser 提取列表 URL → urllib 抓详情页 `<div class="newsbody">`
- **篇数**: 80
- **正文率**: 100%（修复 newsbody 提取后）
- **内容**: 数字人民币/跨境支付/收单监管/支付机构罚单/信用卡政策
- **陷阱**: 列表页 JS 动态加载(urllib 0篇)，必须 Browser 提取 URL。详情页 urllib 可用。
- **脚本**: `scrape_payment_sources.py`

### 金融时报 (financialnews.com.cn)
- **URL**: `financialnews.com.cn/` (首页)
- **方法**: urllib 直接抓
- **篇数**: 177
- **正文率**: 100%
- **内容**: **央行主管媒体**，银行/外汇/金融科技/信用卡专题。信用卡业务观察、支付行业分析等
- **陷阱**: 正文无特殊容器，直接拆 HTML 取>30字行
- **脚本**: `scrape_financialnews.py`

### 百度 AI Search 补全
- **方法**: 百度 AI Search API (80次/天)
- **篇数**: 8-18
- **正文率**: ~80%
- **用途**: 抓常规爬虫遗漏的重大事件（领导变动/大额处罚/新规发布）
- **验证要求**: 每条至少2源交叉确认
- **脚本**: `search_supplement.py`

## ❌ 已废弃（有根本性缺陷）

### PCAC 支付清算协会 (pcac.org.cn)
- **废弃原因**: 
  1. 正文 JS 渲染(`pageId=607959` 详情页返回 "loading..." 空壳)
  2. 90% 文章为 PBC/新华社转载（与已有数据重复,被去重清0）
  3. PDF 文件混入（`%PDF-1.5` 二进制）
  4. 页面模板日期 "今天是2019年10月30日" 标记在全部文章
  5. 反诈宣传/旧闻等低质内容混入
- **结论**: **禁止使用。不要在 PCAC 上浪费更多时间。**

### 金投信用卡 (credit.cngold.org)
- **废弃原因**: 
  1. 58篇文章全是信用卡促销优惠（"邮储信用卡周六5折"）
  2. LLM 正确过滤为不相关（促销 ≠ 监管资讯）
- **结论**: 作为信用卡优惠信息源可能有价值，但作为监管资讯源不可用。

### 北京政务网任免 (beijing.gov.cn/rsxx/rsrm/)
- **废弃原因**: 全是区长/检察长/法院副院长等北京市政府任免，与金融监管零交集
- **结论**: **不要放入 Sheet4**。150条中仅15条含"金融"文字（全是笼统的"人大常委会任免名单"）
