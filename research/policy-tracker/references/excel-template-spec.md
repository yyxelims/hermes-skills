# Excel 交付件规格（3 Sheet，严格按此格式）

## 两种领导表格格式

本技能支持两种 Sheet1 格式，按场景选择：

### 格式 A：领导全量档案（静态参考，7 列）
适用于首次交付或定期全量刷新。格式来自用户提供的参考 Excel。

| 机构 | 姓名 | 性别 | 出生 | 学历 | 职务 | 简历（原始官网文本） |

数据来源：`scrape_leaders_full.py` 抓取各机构详情页 + 硬编码基线。
简历需在"更多>>"处截断，剔除文章列表和活动列表等页面噪音。

### 格式 B：领导变动台账（动态追踪，20 列）
适用于日常监测，追踪变化。

| # | 字段名称 | 字段说明 | 填写方式 |
|:--:|----------|----------|:--:|
| 1 | 序号 | 唯一编号 | 自动生成 |
| 2 | 信息分类 | 人事任免 / 分管调整 / 任前公示 | 自动识别 |
| 3 | 发布日期 | 官方信息发布时间 | 自动抓取 |
| 4 | 涉及单位 | 发布信息的委办局全称 | 自动抓取 |
| 5 | 涉及人员 | 变动人员姓名 | 自动提取 |
| 6 | 职务变动 | 新任职务 / 免去职务 | 自动提取 + 人工修正 |
| 7 | 行政级别 | 正局级 / 副局级 / 正处级 / 副处级 | 自动匹配 + 人工修正 |
| 8 | 分管业务领域 | 该领导分管的核心业务范围 | 自动提取 + 人工补充 |
| 9 | 对应卡部业务条线 | 信用卡发卡 / 消费分期 / 收单支付 / 消保合规 / 数字人民币 / 综合对接 | 自动映射 + 人工修正 |
| 10 | 对口内部团队 | 卡部对应的责任团队 | 自动映射 + 人工修正 |
| 11 | 影响等级 | 红色 / 橙色 / 蓝色 | 自动判定 + 人工调整 |
| 12 | 核心影响摘要 | ≤100 字 | 自动生成 + 人工优化 |
| 13 | 建议跟进动作 | 需开展的具体工作 | 人工填写 |
| 14 | 责任人 | 跟进负责人 | 人工填写 |
| 15 | 原文链接 | 官方发布页面 URL | 自动抓取 |
| 16 | 信息来源栏目 | 抓取的具体栏目 | 自动记录 |
| 17 | 首次抓取时间 | 首次监测到的时间 | 自动生成 |
| 18 | 最近更新时间 | 本条信息最后修改时间 | 自动更新 |
| 19 | 跟进状态 | 待核实 / 已确认 / 跟进中 / 已归档 | 人工维护 |
| 20 | 备注 | 其他补充说明 | 人工填写 |

> ⚠️ 条件格式：影响等级=红色时整行红底，橙色时整行黄底。

## Sheet 2：信用卡与支付监管资讯台账

16 个字段，全量记录监管政策、通知、处罚等资讯。

| # | 字段名称 | 字段说明 | 填写方式 |
|:--:|----------|----------|:--:|
| 1 | 序号 | 唯一编号 | 自动生成 |
| 2 | 资讯类型 | 部门规章 / 规范性文件 / 征求意见稿 / 处罚通报 / 监管动态 / 地方政策 | 自动识别 + 人工修正 |
| 3 | 发布日期 | 文件正式发布时间 | 自动抓取 |
| 4 | 发布单位 | 发文机构全称 | 自动抓取 |
| 5 | 文件文号 | 官方文件编号（如有） | 自动提取 |
| 6 | 文件标题 | 官方原文标题 | 自动抓取 |
| 7 | 核心业务标签 | 发卡 / 分期 / 收单 / 消保 / 反洗钱 / 数币 / 跨境 | 自动匹配 + 人工补充 |
| 8 | 核心内容摘要 | ≤200 字 | 自动生成 + 人工优化 |
| 9 | 关键时间节点 | 生效日期 / 整改截止 / 征求意见截止 | 自动提取 + 人工修正 |
| 10 | 影响等级 | 红色 / 橙色 / 蓝色 | 自动判定 + 人工调整 |
| 11 | 对我行业务影响 | 具体业务影响 | 人工填写 |
| 12 | 责任团队 | 牵头内部团队 | 自动映射 + 人工修正 |
| 13 | 原文链接 | URL | 自动抓取 |
| 14 | 抓取时间 | 首次监测到的时间 | 自动生成 |
| 15 | 跟进状态 | 待研判 / 评估中 / 已落地 / 已归档 | 人工维护 |
| 16 | 备注 | 其他 | 人工填写 |

## Sheet 3：本周重点动态汇总

自动筛选红/橙等级条目，无需人工维护。三个板块：

| 板块 | 来源 | 字段 |
|------|------|------|
| 人事动态重点 | Sheet1 筛选本周 红/橙 | 序号、涉及单位、人员、变动情况、影响等级、核心影响 |
| 监管资讯重点 | Sheet2 筛选本周 红/橙 | 序号、发布单位、文件标题、影响等级、核心要点 |
| 待跟进事项 | 自动提取待跟进状态项 | 序号、事项内容、责任人、截止时间 |

## 样式规范

- 表头：深蓝底(#1B2A4A) 白字，Microsoft YaHei 字体
- 斑马纹：偶数行浅灰底(#F5F5F5)
- 红色行：浅红底(#FFD7D7)
- 橙色行：浅黄底(#FFF0D0)
- 所有单元格有边框，自动换行
- 不能接受的简化：用"来源类型"替代"涉及单位"、用"方法"替代"资讯类型"、省略任何指定字段
