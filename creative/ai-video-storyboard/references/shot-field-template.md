# 逐镜字段规范与提示词结构

## 一、镜头数据字段（生成器的 SHOTS 元素）

```python
{
 "no": "S07",              # 镜号，长段落用 S31-1/S31-2 分段
 "title": "点钞机清点",     # 4-10 字小标题
 "dur": "5s",              # 单镜 3-9 秒；>8 秒必崩，长台词拆镜
 "size": "特写 → 中近景",   # 景别，允许"→"表示镜内变化
 "cam": "固定 + 轻微推近",  # 运镜
 "visual": "…",            # 画面内容：构图、人物、道具、背景，3-6 句
 "action": "…",            # 人物动作/微表情，用"—"串联动作序列
 "line": "…",              # 台词原文，逐字照抄剧本；空镜留空字符串
 "speaker": "柜员小李",
 "audio": "…",             # 音效 + 本镜 BGM 走向
 "caption": "…",           # 后期要叠的字幕/角标/浮层
 "cn": "【风格】…。【主体】…。…",   # 中文提示词（标签式）
 "en": "cinematic photorealism, …, no brand logo",  # 英文提示词（逗号流）
 "first": "…",             # 首帧图提示词（图生视频用）
 "note": "…",              # 本镜专属生成要点/坑
}
```

## 二、中文提示词标签结构（固定 7 段）

| 标签 | 写什么 |
|---|---|
| `【风格】` | 电影感写实 / 纪实 / 微距质感 / 情绪张力 等，+ 分辨率 + 本镜氛围词 |
| `【主体】` | 角色锚点原样复述（年龄、脸型、发型、服装、配饰）或道具全名 |
| `【动作】` | 用"—"或"、"串联动作序列，含微表情 |
| `【环境】` | 柜台/大堂/背景元素 + 虚化程度 |
| `【镜头】` | 景别 + 机位 + 构图 + 景深 + 人物在画面中的位置 |
| `【光线】` | 光源方向 + 质感 + 色温（有价：全片统一 5000K 或按段落变化） |
| `【画质】` | 超高清 + 稳定 + 约束词（手部解剖正确 / 内容不可辨识 / 无品牌标识） |

## 三、英文提示词写法

逗号流关键词，**与中文同信息量**，不简写。末尾统一追加：

```
..., ultra HD, stable camera, anatomically correct hands with five fingers,
no brand logo, screen content unreadable
```

## 四、首帧图提示词写法

一段静态单帧描述（150-250 字），格式：`景别，主体+锚点，动作定格，环境，光线，质感，画幅`。
用途：图生视频的首帧 / 主体参考。全片同一角色必须用同一张定妆图。

## 六、拆镜判定速查

| 原剧本情况 | 处理 |
|---|---|
| 一句台词 > 40 字 | 拆成 2-3 镜 + 插入听者反应镜 |
| 括号里的动作提示（"（动作：…）"） | 单独成镜（手部/道具特写） |
| 大段并列法条/条款 | 每条一镜，字幕条全屏浮层 |
| 情绪峰值句 | 单独给近景 + 反应镜，前后形成"激动→解释→平复"曲线 |
| 无台词过渡 | 给空镜/道具插入镜做转场，掩盖连续性瑕疵 |
