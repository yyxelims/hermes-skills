# 量化金融概念词典

个人量化策略开发必备名词与概念，按学习顺序排列。

---

## 一、收益率

### 简单收益率 (Simple Return)
```
R_t = (P_t - P_{t-1}) / P_{t-1}
```
最直观的收益率。缺点：多期不满足可加性，分布不对称。

### 对数收益率 (Log Return)
```
r_t = ln(P_t / P_{t-1})
```
优点：多期可加（总和 = 首尾对数差），近似正态分布，适合统计建模。**量化里优先用对数收益。**

### 年化 (Annualization)
- 日收益率 → 年化收益率：`日收益率均值 × 252`（252 ≈ 一年交易日）
- 日波动率 → 年化波动率：`日波动率 × √252`

> 关键洞察：收益跟时间线性增长，风险跟时间平方根增长。

## 二、风险指标

### 波动率 (Volatility)
收益率的标准差，衡量不确定性。年化波动率是最常用的风险度量。

### 最大回撤 (Max Drawdown / MDD)
```
MDD = max((累计最高净值 - 当前净值) / 累计最高净值)
```
从最高点到最低点的最大跌幅。回答"最坏情况亏多少"。
- 回撤 20% 需要涨 25% 才能回本
- 回撤 50% 需要涨 100% 才能回本

### 在险价值 (Value at Risk / VaR)
在给定置信水平下，未来一段时间的最大可能损失。
- 95% VaR = 1 美元：有 95% 把握亏损不超过 1 美元
- 计算方法：历史模拟法（最直接）和参数法（假设正态分布）

### 下行风险 (Downside Deviation)
只看负收益的波动率。比总波动率更符合"风险就是亏损"的直觉。

## 三、绩效指标

### 夏普比率 (Sharpe Ratio)
```
Sharpe = (年化收益率 - 无风险利率) / 年化波动率
```
衡量"每承担一单位风险，赚了多少超额收益"。
- \>1：不错
- \>2：优秀
- \>3：极好（但小心过度拟合）

### 卡玛比率 (Calmar Ratio)
```
Calmar = 年化收益率 / |最大回撤|
```
用最大回撤代替波动率做分母，更直观地衡量"承受最大痛苦换来的回报"。

### 索提诺比率 (Sortino Ratio)
```
Sortino = (年化收益率 - 无风险利率) / 下行波动率
```
夏普比率的改进版，只看下行风险，更适合非对称收益分布。

### 信息比率 (Information Ratio)
```
IR = (策略收益 - 基准收益) / 跟踪误差
```
衡量策略相对基准的"一致性"。

### Alpha
策略超越 CAPM 预测的超额收益。Alpha 为正 → 策略有真本事（不只是靠市场涨跌赚钱）。

### Beta
```
β = Cov(R_策略, R_市场) / Var(R_市场)
```
策略对市场波动的敏感度。β=1 跟市场同步，β>1 比市场更激进，β<1 更保守。

### 胜率 (Win Rate)
盈利交易次数 / 总交易次数。**胜率不重要，盈亏比 + 胜率才重要。**

### 盈亏比 (Profit Factor)
```
盈亏比 = 总盈利 / |总亏损|
```
- 胜率 40% + 盈亏比 3:1 → 能赚钱
- 胜率 80% + 盈亏比 0.5:1 → 会亏钱

## 四、资产定价

### CAPM (资本资产定价模型)
```
E(R_i) = R_f + β_i × (E(R_m) - R_f)
```
资产的期望收益 = 无风险利率 + 风险补偿。风险补偿 = 系统风险(β) × 市场风险溢价。

核心假设：只有系统风险（市场风险）被定价，个股特有风险可以通过分散化消除。

### 系统风险 vs 特有风险
- **系统风险 (Systematic Risk)**：整个市场共有的风险，无法通过分散化消除。由 Beta 衡量。
- **特有风险 (Idiosyncratic Risk)**：个股特有的风险，可以通过分散化消除。

## 五、数据与预处理

### 复权 (Adjustment)
股价在分红、拆股后会跳空。复权修正这些跳空：
- **前复权 (qfq)**：当前价不变，历史价按比例调整。最常用。
- **后复权 (hfq)**：历史价不变，当前价调整。

### 幸存者偏差 (Survivorship Bias)
回测时用现在还活着的股票列表→结果虚高。因为已经退市的烂股票没被算进去。

### 前视偏差 (Look-ahead Bias)
策略用到了当时还不存在的数据。比如"用今天收盘价决定今天买入"→信号计算应该用前一天数据。

### 停牌 (Suspension)
股票暂停交易期间，价格不变。回测中应识别并处理，否则误判为"策略躲过了大跌"。

### 异常值处理
- **MAD (Median Absolute Deviation)**：比 Z-score 更鲁棒，不受极端值影响。
- **Winsorize（缩尾）**：把超出分位数的值截断到分位数边界，保留数据量。

### 缺失值处理
金融数据的缺失值**不能用均值填充**。优先：前向填充(ffill) > 线性插值 > 剔除。

## 六、技术指标

### 简单移动平均 (SMA)
过去 N 天的平均价格。用于判断趋势方向。

### 指数移动平均 (EMA)
近期价格权重更大，比 SMA 更灵敏。

### MACD
```
MACD = EMA(12) - EMA(26)
信号线 = EMA(MACD, 9)
```
金叉（MACD 上穿信号线）→看涨；死叉→看跌。

### RSI (相对强弱指数)
```
RSI = 100 - 100 / (1 + 平均涨幅/平均跌幅)
```
0-100 之间。>70 超买（可能回调），<30 超卖（可能反弹）。

### 布林带 (Bollinger Bands)
```
中轨 = SMA(20)
上轨 = 中轨 + 2 × σ(20)
下轨 = 中轨 - 2 × σ(20)
```
价格在带内波动的概率约 95%。突破上/下轨→可能趋势启动或反转。

## 七、回测

### 向量化回测 (Vectorized Backtest)
用 pandas 对整个时间序列做矩阵运算，一次算出所有结果。速度快，适合简单策略快速验证。缺点：难以模拟复杂订单逻辑和日内交易。

### 事件驱动回测 (Event-driven Backtest)
逐根 K 线遍历，模拟真实交易流程（信号→下单→成交→持仓）。Backtrader 是典型框架。更真实，但更慢。

### 过拟合 (Overfitting)
参数调得太好，样本内漂亮但样本外崩盘。对策：样本外测试、交叉验证、参数敏感性分析、策略尽量简单。

### 数据挖掘偏差 (Data Snooping)
测了 1000 个策略，总有一个看起来很好→但只是运气。对策：控制测试数量、调整显著性阈值、用独立验证集。

### 样本外测试 (Out-of-sample Testing)
把数据切成训练集和测试集，只用训练集开发策略，用测试集验证。时间序列必须用时间顺序分割（不能用随机 K-fold）。

### 交易成本
- **佣金**：券商手续费，通常万分之几到千分之几
- **滑点 (Slippage)**：下单价格和成交价格的差距
- **冲击成本 (Market Impact)**：大单推高价格，尤其是小盘股

## 八、策略类型

### 趋势跟踪 (Trend Following)
"顺势而为"。假设：涨的继续涨，跌的继续跌。
- 双均线交叉、唐奇安通道突破、动量策略
- 优点：大趋势中赚大钱
- 缺点：震荡市频繁止损

### 均值回归 (Mean Reversion)
"高抛低吸"。假设：价格会回到均值。
- 布林带、RSI 超买超卖、配对交易
- 优点：震荡市中频繁盈利
- 缺点：大趋势中逆势扛单，可能爆仓

### 配对交易 (Pairs Trading)
找两只高度相关的股票（协整检验），做多弱势股同时做空强势股，赌价差回归。
- 核心工具：协整检验 (Cointegration Test)
- 信号：z-score = (价差 - 均值价差) / 价差标准差

### 因子策略 (Factor Investing)
用多个因子（价值、动量、质量等）给股票打分，买高分卖低分。
- **IC (Information Coefficient)**：因子值与未来收益的秩相关系数。绝对值越大越好。
- **IC_IR**：IC 均值 / IC 标准差。衡量因子预测的稳定性。

### 机器学习策略
用 ML 模型预测收益率（回归）或涨跌方向（分类）。
- 特征工程比模型选择更重要
- 必须用时间序列交叉验证
- 过拟合是头号敌人

## 九、仓位与组合

### 凯利公式 (Kelly Criterion)
```
f* = (p × b - (1 - p)) / b
p = 胜率, b = 盈亏比
```
最优下注比例，最大化长期对数收益。实践中通常用 1/4 凯利。

### 有效前沿 (Efficient Frontier)
给定一组资产，所有"给定风险下收益最高"的组合构成的曲线。上半部分是有效的，下半部分是无效的。

### 最大夏普组合 (Tangency Portfolio)
有效前沿上夏普比率最高的点。理论上的最优组合。

### 最小方差组合 (Minimum Variance)
有效前沿上风险最低的点。防守型配置。

### 风险平价 (Risk Parity)
每类资产对组合的总风险贡献相等。解决了 Markowitz 过度集中少数高收益资产的问题。

## 十、风险控制

### 止损 (Stop Loss)
- **固定止损**：亏 X% 就卖
- **追踪止损 (Trailing Stop)**：从最高点回撤 X% 就卖
- **ATR 止损**：止损距离 = N × ATR，随波动率动态调整

### 凯利与仓位
- 仓位过大会因波动性拖累（Volatility Drag）反而降低长期收益
- 凯利公式给出的 f* 是理论上限，实践中取 1/2 或更低

### 波动性拖累 (Volatility Drag)
年化算术平均收益相同的情况下，波动率越高，实际复合收益率越低。
- 涨 50% 再跌 50% → 亏 25%（不是回本！）
