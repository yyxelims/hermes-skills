## NN特征重要性 (L1 norm, 115场)

```
1. overround      (市场效率)
2. dr_prev        (前一日平局率) ← 交替规律是真实信号
3. dr_roll2       (前两日均值)
4. spread         (赔率极差)
5. Vy             (框架投Y票数)
```

## 关键结论

1. 2026平局率42.1%是历史2倍——任何历史模型都会系统性低估平局
2. 框架投票0/19——不可用于方向预测
3. 交替规律dr_prev是#2特征，但在低平局环境下从未触发过
4. 迁移学习反效果——分布漂移太严重
