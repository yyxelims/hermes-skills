# 对公客户信息挖掘（Enterprise Customer Research）

通过公司名称+统一社会信用代码，在互联网上系统性检索对公客户信息，用于客户关系挖掘、风险排查、营销机会发现。

## 数据源分层

### 第一层：基础工商信息（信用代码天然入口）

| 平台 | 能拿到的 | 方法 |
|------|---------|------|
| 国家企业信用信息公示系统 (gsxt.gov.cn) | 注册资本、成立日期、法人、股东、经营范围、行政处罚 | 信用代码直查，官方权威 |
| 天眼查 (tianyancha.com) | 股权穿透图、关联企业、司法风险、招投标记录 | 浏览器打开，信用代码比公司名更精准 |
| 企查查 (qichacha.com) | 同上，结构化数据 | 付费 API 可批量查 |

关键价值：股权穿透 → 母公司/实控人；关联企业 → 交叉销售机会。

### 第二层：经营动态（判断客户"活得好不好"）

| 渠道 | 能拿到的 | 搜索方式 |
|------|---------|---------|
| 百度 AI 搜索 | 最新新闻、项目动态、行业报道 | `"{公司名} 中标"` / `"{公司名} 签约"` / `"{公司名} 新闻"` |
| 中国政府采购网 (ccgp.gov.cn) | 政府采购中标公告 | `"{公司名} site:ccgp.gov.cn"` |
| 各地公共资源交易中心 | 地方招投标 | 按省份分别搜索 |
| 巨潮资讯 (cninfo.com.cn) | 上市公司公告 | `"{公司名} site:cninfo.com.cn"` |
| 微信公众号 | 是否有公众号、业务动态 | 百度搜 `"{公司名} 公众号"` 或用微信搜一搜 |

关键价值：中标公告=客户有预算；负面新闻=风险信号；公众号活跃=对外传播需求。

### 第三层：财务健康度

| 渠道 | 能拿到的 | 方法 |
|------|---------|------|
| 天眼查/企查查 | 注册资本、实缴资本、社保人数 | 浏览器查 |
| 巨潮资讯 | 完整财务报表 | 上市公司客户 |
| 中国裁判文书网 | 涉诉情况 | `"{公司名} site:wenshu.court.gov.cn"` |
| 中国执行信息公开网 | 失信被执行人 | `"{公司名} 被执行人"` |

关键价值：社保人数=真实员工规模；涉诉多=经营风险。

### 第四层：业务需求信号（营销切入点）

| 信号 | 搜索方式 | 含义 |
|------|---------|------|
| 招聘信息 | `"{公司名} 招聘"` → 看岗位 | 招销售=扩张；招IT=数字化需求 |
| 招标/中标 | `"{公司名} 招标"` `"{公司名} 中标"` | 采购什么=卖什么 |
| 专利/软著 | `"{公司名} 专利"` `"{公司名} site:cnipa.gov.cn"` | 技术投入方向 |
| 融资新闻 | `"{公司名} 融资"` | 有预算 |

## 批量执行流水线

```
第一步：百度 AI 搜索批量跑（80次/天，非深度~10秒/条）
  每家公司 3 个 query：
    - "{公司名} 公司 简介 主营业务"
    - "{公司名} 中标 OR 签约 OR 合作"
    - "{公司名} 风险 OR 诉讼 OR 处罚"
  汇总关键词命中 → 快速分级（A/B/C）

第二步：浏览器定向深挖（仅 A 级客户）
  天眼查：股权穿透 + 司法风险
  招投标网：中标历史
  公众号搜索：微信生态存在感

第三步：输出客户画像报告
  每家公司一张卡：基本信息 + 经营动态 + 风险信号 + 业务机会
```

## 现实限制

- 天眼查/企查查：免费版看摘要，详细信息/批量导出需付费
- 国家企业信用信息公示系统：有验证码，无法程序化批量抓取
- 政府采购网：各省份系统独立，数据分散
- 征信报告：正规渠道需客户授权（央行征信），不在公开信息范围内
