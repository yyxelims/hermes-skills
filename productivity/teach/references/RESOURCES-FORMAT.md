# RESOURCES.md Format

`RESOURCES.md` lives at the workspace root. It contains high-quality, high-trust resources that ground the teaching in real knowledge.

## Template

```md
# Resources

## Primary
- **[Title]** — <Type: book / course / paper / documentation / tutorial>
  - URL: <link>
  - Why: <1 sentence on why this is trustworthy and relevant>

## Supplementary
- **[Title]** — <Type>
  - URL: <link>
  - Why: <1 sentence>

## Communities
- **[Name]** — <Type: forum / subreddit / Discord / local group>
  - URL: <link>
  - Why: <why this community is worth joining>
```

## Rules

- Primary resources are the core curriculum — the 2–5 sources you will cite most. Everything else is supplementary.
- Every resource must have a "Why" — don't just dump links.
- Communities are for Acquiring Wisdom (see SKILL.md philosophy).
- Update as you discover better sources. Stale resources mislead future sessions.
